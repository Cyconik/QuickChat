QuickChat Mesh App
Zero-Network Offline Communication

QuickChat lets entire groups and nearby people chat together automatically using decentralized mesh relays without cellular network or data pack.

📡 How Zero-Internet Nearby Chat Works:
  1. Portable Hotspot Mode (No SIM/Data needed): One phone turns on Hotspot, nearby phones connect. All users discover each other and chat 100% offline!
  2. 1-Tap Offline QR Link: Tap "Offline Connect" -> Show QR or Scan QR with camera. Connects directly peer-to-peer via WebRTC DataChannels.
  3. Autonomous 5km Mesh Forwarding: If someone is out of range, intermediate phones automatically store and forward the encrypted packets.
  4. Permanent Groups: Create groups anytime. Groups stay saved permanently and sync to all nearby devices.
